## 技术经验
- docx 文本替换：run 级失效的两种情形——①文本在 hyperlink 内（par.runs 不含）②run 间有额外空格导致模式失配。兜底：按 w:t 拼接整段重写（首 w:t 放全文、其余清空）。
- docx 表格插行：deepcopy 相邻 tr 后 addnext，再逐格 set 文本（保首段首 run 样式）。
- pptx 卡片横排页检测：按 AUTO_SHAPE + top 聚类 + 宽度一致判断，比按形状位置窗口更准。
- 讲义 Part1/Part2 模块编号同名（都叫模块 1-7 且都有"页 4-x"引用），跨篇引用必须写"PPT1 模块 N / PPT2 模块 N"区分。
