## 一、听完初级，为什么还会"不会做"？

多数企业培训完初级后会卡在三个"不会"上：

| **常见卡点** | **中级怎么解** |
|---|---|
| **"会聊天，不会找场景"** | M1 机会画布六维打分，从自己岗位的低效环节里识别并排序 3 个真场景 |
| **"懂原理，不敢动手"** | 每模块带数据实操、交"看得见的产出"，全程零代码，结课交迷你项目 |
| **"有想法，报不了项目"** | 会算 ROI、会写试点章程、会按国发 11 号"人工智能+"条款争取试点与标杆资源 |

中级是五级能力塔的 **L2 业务认知 + L3 场景应用**层，占全体系 30% 课时。对象是已完成初级、具备 AI 通识与提示词基础的业务骨干、流程负责人与职能部门核心。目标不再是"敢用 AI"，而是**用 AI 解决自己岗位上的真问题**——学完即具备"企业内部 AI 场景设计师"的能力。

与初级的三条根本差异：**从工具到场景**（练预测预警、智能审核、知识库助手等通用业务场景）、**从听懂到做出**（每模块交产出）、**从知道政策到会用政策**（把国发 11 号《"人工智能+"行动意见》当立项指挥棒）。

> 制造/行业客户（设备维护、视觉质检、产线优化）可加开《行业案例包·制造业》，通用课主线不展开。

## 二、课程总览：落地层 24 课时

| **项目** | **说明** |
|---|---|
| **对象** | 已完成初级的业务骨干、流程负责人、职能部门核心（行政 / 业务 / 技术 / 市场 / 管理层，重点数据、审核、运营、知识四类岗位） |
| **时长** | **24 课时**（8 模块 × 3h），标准 3 天；可压缩 12h / 1.5 天，或按岗位 6h 专精 |
| **结构** | **8 个模块**：企业 AI 与机会地图 → 数据驱动的预测与预警 → 智能审核与 AI 判定 → 流程优化与资源调度 → RAG 助手 → 落地管理 → 负责任 AI → 实战工作坊 |
| **设计** | 技术线（怎么做）+ 业务线（为什么做 / 谁做成了）全程并行 |
| **实操** | 零代码工具栈 + 10 个带数据的实战活动包，每模块交产出物 |
| **考核** | 小测 15% + 实操 35% + 案例分析 20% + 迷你项目 30% |
| **认证** | 总分 ≥70 发《中级 AI 场景师》证书；≥85 加注"优秀场景设计"，入 AI 倡导者储备池 |

## 三、8 大模块：从机会地图到实战答辩

| **#** | **模块** | **学完你能** |
|---|---|---|
| **M1** | 企业 AI 与机会地图 | 读懂国发 11 号四类要求；用机会画布六维打分，在本岗位识别并排序 3 个 AI 场景 |
| **M2** | 数据驱动的预测与预警 | 读懂业务时序数据趋势，设计"正常 / 预警 / 停机"三段阈值与处置权 |
| **M3** | 智能审核与 AI 判定 | 手算混淆矩阵，判断一个审核/判定模型能不能上线——知道"准确率 96% 仍不够用" |
| **M4** | 流程优化与资源调度 | 会算节拍、找瓶颈、做 ABC+关键度分级、算批量与看板，说出 AI 在哪一步补位 |
| **M5** | 生成式 AI 与知识库助手（RAG） | 零代码搭一个接地式"岗位知识助手"，带来源引用、不确定会说、证据缺失会拒答 |
| **M6** | AI 项目落地与变革管理 | 过"数据就绪门槛"、写一页试点章程 A3、算清 ROI，知道补贴 / 标杆 / 试点怎么拿 |
| **M7** | 负责任 AI | 按 NIST AI RMF 四步给场景配治理动作，说清六大失效模式与停止条件 |
| **M8** | 场景实战工作坊 | 四选一迷你项目组队冲刺，向"管理层"做 8 分钟答辩 + 5 分钟质询 |

每个模块配 1 个带数据的实战活动包（共 10 个，含真实数据文件），讲师现场带练、学员逐格填表。

## 四、双线设计：一节课，两条腿走路

技术线解决"怎么做"，业务线解决"为什么做、谁做成了"——两条线在每个模块里同时推进：

| **模块** | **技术线（怎么做）** | **业务线（为什么做 / 谁做成了）** |
|---|---|---|
| **M1** | AI 五种补位能力、技术演进四阶 | 政策"人工智能+"逐条解读、机会地图、低效走查 |
| **M2** | 时序数据、特征与健康指标、风险评分、阈值分段 | 跨行业预测案例（零售需求 / 金融风险 / 设备寿命） |
| **M3** | 分类/检测/异常检测、混淆矩阵、精确率与召回率 | 跨行业审核案例（单据 / 合规 / 客服质检 / 影像初筛） |
| **M4** | 节拍/瓶颈计算、需求感知、异常检测、补货推荐 | ABC+关键度真实台账、看板信号-响应、断料/断货失效模式 |
| **M5** | LLM、RAG 五步、提示词进阶 | 企业知识散落治理、受控发布流程、岗位 Copilot |
| **M6** | AI 生命周期六阶、数据就绪门槛、系统与 API 集成 | 试点章程、PDCA、变革管理、地方配套资源怎么拿 |
| **M7** | 可解释、漂移监控、人在回路、数据安全 | 政策安全与治理章节、Agent 与具身智能趋势 |
| **M8** | 四选一迷你项目搭建 | 分岗位实战 + 管理层答辩 |

课堂纪律：每节课必须回答三问——"这跟我岗位有什么关系？""我不写代码怎么用？""用了能省多少钱 / 事？"

## 六、政策当指挥棒：作业攒起来就是申报书

初级讲"政策是什么"，中级讲"国家要什么、资源怎么拿、场景怎么对标"。三份必知文件：

| **文件** | **编号** | **中级要抓的重点** |
|---|---|---|
| **国务院《关于深入实施"人工智能+"行动的意见》** | 国发〔2025〕11 号 | **本级主文件**：AI 与经济社会各领域深度融合，场景清单、智能体培育、标杆与试点遴选 |
| **"十五五"规划与地方"人工智能+"配套** | 各省市 2026 起陆续出台 | 地方补贴、试点、标杆通道；讲师按客户所在地替换具体名称 |
| **行业专项（可选加开）** | 如《"人工智能+制造"专项行动》工信部联科〔2025〕279 号 | 仅制造客户加开《行业案例包·制造业》时引用，通用课不展开 |

**四条资源通道**：中央部委（典型场景征集 / 优秀解决方案）→ 省级（数字化转型标杆 / 行业试点认定）→ 市区县（技改补贴 / 上云券 / 免费诊断名额）→ 标准荣誉（数字化转型能力成熟度评级）。门槛从低到高，中级学员的"第一个试点"最适合从市区县通道起步。

| **申报材料要项** | **本课程哪个产出直接可用** |
|---|---|
| **场景描述与痛点** | M1 机会画布 + 问题陈述 |
| **现状基线数据** | M2 / M3 / M4 的基线表（差错、周期、成本） |
| **技术方案** | M2 / M3 / M5 的方案设计单 |
| **人机分工与安全措施** | M7 治理清单 + 人在回路设计 |
| **效益测算** | M6 ROI 表 |
| **推广计划** | M8 迷你项目答辩稿 |

**一句话卖点："这门课的作业，攒起来就是一份试点申报书。"**

注：政策目标量级（2027 年约 1000 个行业智能体 / 500 个典型场景 / 1000 家标杆企业）按公开政策文本与官方解读整理，正式引用前请以文件原文核对。

## 七、考核与认证：中级 AI 场景师

考核不考记忆，考"能不能做出东西、讲得清楚"：

| **考核项** | **权重** | **形式** |
|---|---|---|
| **小测** | **15%** | 每模块 5 题 × 8 模块，线上或纸质 |
| **实操** | **35%** | M1–M7 每模块交付物，按证据清单打勾 |
| **案例分析** | **20%** | 指定案例书面分析（如：给混淆矩阵数据，判断能否上线并说明理由） |
| **迷你项目** | **30%** | M8 分组产出 + 答辩（同伴互评 20% + 讲师评 80%） |

**发证标准**：总分 ≥70 发《中级 AI 场景师》证书；总分 ≥85 且迷你项目 ≥85 加注"优秀场景设计"，推荐进入企业 AI 倡导者储备池（对接高级层八支柱）；未达标者补交实操产出 + 一次复评。

## 八、标杆数据：每一模块都有真案例

| **案例** | **公开结果** |
|---|---|
| **零售需求预测（M2）** | 库存周转提升、缺货率下降（跨行业预测预警） |
| **金融风险预警（M2）** | 逾期识别提前量提升（时序风险评分） |
| **单据/合规智能审核（M3）** | 审核周期缩短、漏检率下降（混淆矩阵口径） |
| **客服质检（M3）** | 全量质检替代抽检，一致率提升 |
| **WEF 灯塔工厂（M7）** | 全球 220+ 站点，生成式 AI 约占头部方案 1/4 |

还有课堂专属"反面案例"：某审核模型整体准确率 **96%**，但 10 个关键件漏判 2 个（召回率仅 80%）——判定"停止自动判定，只作辅助分诊"。**会判断"该停的模型"，是中级和初级最大的区别。**

注：制造行业深案例（陕汽 / 西门子 / 博世）见《行业案例包·制造业》，按客户行业加开。

## 十、师资与质量保障

- **双讲师制**——技术讲师（AI 工程背景）+ 业务场景讲师（行业/流程背景）各管一条线，业务术语由内行讲。
- **10 个带数据活动包**——每个模块有真实数据文件与评分证据清单，学练评一体。
- **溯源合规**——标杆数据、政策条款、方法论均注明出处，客户尽调可查；政策目标量级标注"量级 / 方向"，引用前核对原文。
- **持续迭代**——每期依据迷你项目答辩质量与学员岗位采纳情况修订，案例库与政策映射季度更新。
