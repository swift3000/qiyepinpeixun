## 三、考核与认证

- 权重：小测 15 / 实操 35 / 案例分析 20 / 迷你项目 30
- 《中级 AI 场景师》：总分 ≥70 通过
- ≥85 且项目 ≥85 →「优秀场景设计」，进入倡导者储备池（对接高级班与试点申报）

## 四、核心卖点（对外口径）

1. **每个模块一个可带走的方法**：机会画布 / 三段阈值 / 混淆矩阵 / 三钟 / RAG 五步 / ROI 五步……
2. **政策即立项书**：279 号文四类要求 → 申报材料六项对应，「这门课的作业，攒起来就是一份试点申报书」
3. **标杆铁案**：96% 准确率漏判铁案（"整体漂亮但关键类别漏判=停"）、跨行业预测 -50%/-25%（制造客户加开展开陕汽/西门子/博世）
4. **零代码**：DeepSeek V4/通义 Qwen3.8-Max/豆包 2.1/智谱 GLM-5.2/Kimi K3 + 知识库平台（Dify）+ Excel/BI + 5 个在线流程工具
