## 四、核心卖点（对外口径）

1. **每个模块一个可带走的方法**：机会画布 / 三段阈值 / 混淆矩阵 / 三钟 / RAG 五步 / ROI 五步……
2. **政策即立项书**：279 号文四类要求 → 申报材料六项对应，「这门课的作业，攒起来就是一份试点申报书」
3. **标杆铁案**：陕汽 10 秒预警、96% 召回铁案、博世 -40%、西门子 -50%/-25%
4. **零代码**：DeepSeek/通义/豆包 + 知识库平台（Dify）+ Excel/BI + 5 个在线精益工具
