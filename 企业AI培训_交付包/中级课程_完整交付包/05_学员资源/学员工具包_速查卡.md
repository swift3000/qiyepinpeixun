## M1 机会画布六维打分（每维 1-5 分，≥18 分才值得立项）

| 维度 | 问自己 |
|---|---|
| 频次 | 这事多久发生一次？（天天=5 / 每周=3 / 每月=1） |
| 耗时 | 每次卡多久？（>1h=5 / 15min=3 / <5min=1） |
| 出错代价 | 错了多疼？（要赔钱/丢客户=5 / 返工=3 / 无所谓=1） |
| 数据可得 | 有现成数据吗？（系统里有=5 / 要人记=2 / 没有=0） |
| 规则可描述 | 能说出"什么情况怎么办"吗？（全说得清=5 / 大概=3 / 全凭感觉=1） |
| 政策对齐 | 对应"人工智能+"哪一类？（场景/智能体/标杆/安全，沾上加分） |

## M2 三段阈值口诀

**正常 / 预警 / 停机**——每条阈值必须配**处置权**（谁处理、怎么处理、多久响应）。
- 只定阈值不定处置权 = 白定
- 阈值怎么来：看历史分布 + 业务专家拍"疼点"，不要拍脑袋取整
- 预测四阶：**事后复盘 → 统计预测 → 状态监测 → 预测预警**，别跳级

## M3 混淆矩阵手算四格

|  | 实际有问题 | 实际没问题 |
|---|---|---|
| **AI 说有问题** | TP 抓对了 | FP 冤枉了（误报） |
| **AI 说没问题** | FN 漏了（漏检） | TN 放对了 |

- **精确率** = TP/(TP+FP)：AI 报警的可信度
- **召回率** = TP/(TP+FN)：问题被抓全没有
- 铁律：**召回率不达标的模型，只能做辅助分诊，不能自动判定**（96% 准确率 ≠ 能上线）
- 分诊阈值调法：漏检疼 → 降阈值多报警；误报烦 → 升阈值

## M4 三个"钟"别混

| 钟 | 公式 | 谁定 |
|---|---|---|
| 节拍 Takt | 净可用时间 ÷ 客户需求 | 客户 |
| 周期 Cycle | 本环节做一件要多久 | 自己 |
| 交付 Lead time | 需求到交付全程 | 全程 |

- **瓶颈 = 周期 ≥ 节拍的那一环**，改进只改瓶颈
- ABC 分级：A 类（高价值）重点管，C 类（低价值）别浪费管理成本
- 看板数量 ≈ 需求波动 × 响应时间，先算再加减

## M5 RAG 助手五步

**切分 → 嵌入 → 向量库 → 检索 → 增强生成**

- 接地三要件：答案带来源引用 / 不确定会说"不知道" / 证据缺失会拒答
- 翻车演示必做：故意问库外问题，证明它会拒答
- 受控发布：先内测 → 评审 → 小范围 → 全员，每步有回退

## M6 ROI 五步 + 试点章程 A3

ROI 五步：**基线 → 实验 → 价值量化 → 危害/成本扣减 → 投资回收期**
- 区分**预计价值**与**已验证价值**，写汇报时分开列
- 治理成本（人终审时间/培训/维护）要进分母
- A3 六字段：问题 / 基线 / 目标 / 范围 / 责任人 / 时间盒 + 人机分工 + 停止条件

## M7 NIST AI RMF 四步（Govern / Map / Measure / Manage）

1. **Govern 治理**：责任人、用途、审批、风险等级、文档
2. **Map 识别**：场景风险有哪些（幻觉/泄露/偏差/依赖）
3. **Measure 度量**：漂移监控、抽检比例、指标看板
4. **Manage 管理**：缓解动作、升级路径、**停止条件写进制度**
- 六大失效模式：数据漂移 / 提示注入 / 过度自信 / 影子使用 / 依赖退化 / 责任真空
- 安全关键场景：**处置权永远归人**

## M8 答辩"三把刀"应答准备（讲师必问）

| 质询 | 你的答案要点 |
|---|---|
| "数据从哪来？" | 来源 + 就绪门槛自查结果 + 缺口怎么补 |
| "错了谁担责？" | 责任人 + 回退方案 + 停止条件 |
| "省的钱怎么验证？" | 基线数字 + 验证方法 + 预计 vs 已验证分开说 |

- 8 分钟讲 = 问题 1min / 方案 2min / 人机分工 1min / ROI 2min / 推广 1min / 政策挂钩 1min
- 讲业务价值，不讲技术细节——听众是管理层
