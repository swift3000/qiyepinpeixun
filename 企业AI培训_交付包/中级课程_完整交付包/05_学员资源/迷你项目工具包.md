# 迷你项目工具包（M8 场景实战工作坊 · 学员用 · 通用企业版 V2.0）

> 用途：M8 分组冲刺 + 答辩的**全套填空模板**——照着填就能交"六件套"。结课即交，不是作业。
> 版本：V2.0 ｜ 2026-09-02 ｜ 对齐《中级大纲》M8 + 迷你项目评分细则（100 分）
> 设计原则：对标头部企业 AI 训练营"结课交可验收项目"标准——**每个字段填完，评分维度就对应上**。

---

## 0. 四选一选题（先定这个，再填下面所有模板）

| 选项 | 项目名 | 适合岗位 | 核心交付 |
|---|---|---|---|
| ① | **预测预警看板** | 数据/预测岗 | 三段阈值 + 趋势看板 + 工单联动 |
| ② | **智能审核试点** | 审核/质量岗 | 混淆矩阵评估 + 分诊阈值 + 人工复检规则 |
| ③ | **流程与资源优化** | 运营/供应链岗 | 需求感知 + ABC/关键度策略 + 补货例外规则 |
| ④ | **岗位知识助手** | 技术/知识岗 | 制度/流程知识库 RAG 助手（可运行） |

**选题三不**：不贪大（一个流程/一个岗位）/ 不无基线（必须有现状数字）/ 不无数据（数据从哪来说不清就别选）。

## 1. 六件套之一：问题与基线（对应评分 20 分）

| 字段 | 填写 |
|---|---|
| 问题一句话（中性陈述，不含"用 AI"） | |
| 现状基线（量化：现在多久/多少次/多少成本） | |
| 为什么现在要解决（业务代价） | |
| 目标（可验证的一句话："把 X 从 A 降到 B"） | |
| 范围边界（做什么/不做什么） | |

> ⚠️ 问题陈述**不能出现"用 AI 解决 XX"**——先说清业务问题，方案是后面填的。出现 = 扣"问题与基线"分。

## 2. 六件套之二：数据来源与就绪判定（对应评分 15 分）

| 字段 | 填写 |
|---|---|
| 数据来源（系统/表格/人工记录，具体到表名） | |
| 数据量 + 时间跨度 | |
| 数据就绪门槛自查（10 项，打勾） | □完整 □干净 □可获取 □有权限 □够样本 □有标签 □时效够 □脱敏 □可更新 □有 owner |
| 已知缺口 + 怎么补 | |
| 数据敏感度（绿/黄/红区） | |

> 就绪门槛 **≥7/10** 才建议进入试点；<7 先写"数据补齐计划"再立项。

## 3. 六件套之三：AI 方案与工具（对应评分 20 分）

| 字段 | 填写 |
|---|---|
| 选的方案（最简可靠方法，说明为什么不用更重的） | |
| 用哪个工具/平台（具体到产品） | |
| 方案三版迭代记录（V1 毛坯 / V2 提要求 / V3 定稿，各留一句话） | |
| 为什么这个方案"够用"（不是最强，是对） | |

> 铁律：**不为用大模型而用大模型**。能规则+统计解决就不上 LLM，能 RAG 就不微调。

## 4. 六件套之四：人机分工与回退（对应评分 15 分）

| 环节 | AI 做 | 人做 | 谁担责 |
|---|---|---|---|
| | | | |
| | | | |

- **回退方案**：AI 出问题时，怎么切回人工？（具体动作）
- **停止条件**：什么情况下这个 AI 该停？（写 1-2 条可触发的条件）
- **安全关键动作**：哪些永远归人，AI 只辅助？

## 5. 六件套之五：ROI 测算（对应评分 15 分）

| 项 | 数字 | 备注 |
|---|---|---|
| 基线成本/耗时（现状） | | |
| 预计节省（年化） | | 预计值 |
| 治理成本（人终审/培训/维护） | | 进分母 |
| 净价值 = 节省 − 治理 | | |
| 投资回收期（月） | | |
| 已验证部分（试点已测得的数字） | | 与"预计"分开列 |

> 汇报时**预计 vs 已验证必须分开**——混着说 = 评委一票扣分。

## 7. 答辩 PPT 骨架（≤10 页，8 分钟讲）

| 页 | 内容 | 时长 |
|---|---|---|
| P1 | 标题 + 一句话问题 | 0.5min |
| P2 | 问题与基线（现状数字） | 1min |
| P3 | 方案（最简可靠方法 + 为什么够用） | 2min |
| P4 | 人机分工与停止条件 | 1min |
| P5 | ROI（预计 vs 已验证分开） | 2min |
| P6 | 推广路径 + 政策挂钩 | 1min |
| P7 | 一句话收尾（"下一步我要……"） | 0.5min |

> 讲**业务价值**，不讲技术细节——听众是管理层，不是工程师。

## 8. 30-60-90 天采纳指南（结课后自己用 · 对标头部企业"行为改变才叫成功"标准）

> 培训结束不是终点。**30 天后你还没用起来，这门课就白上了。**

### 第 30 天（用起来）
- [ ] 把迷你项目的"岗位知识助手/审核/看板"真正跑起来（哪怕只覆盖 1 个岗位）
- [ ] 每天至少用 AI 干 1 件真实工作，记一句话（做了什么/省了多少）
- [ ] 找 1 个同事演示一遍（教别人 = 学得最快）
- [ ] 把速查卡贴工位，卡壳时翻 M2/M3 口诀

### 第 60 天（改流程）
- [ ] 把 1 个 AI 动作**写进正式流程/SOP**（不是个人习惯，是制度）
- [ ] 做一次数据复查：阈值/准确率/召回率有没有漂移？
- [ ] 收集 3 条"AI 帮上忙/帮倒忙"的真实案例
- [ ] 如果做了预测/审核类：跑一次"该停没停"的自检（召回率达标吗？）

### 第 90 天（算清账）
- [ ] 用第 5 节 ROI 模板，把 90 天的**已验证数字**填进去（不是预计）
- [ ] 写 1 页"90 天复盘"：哪步最值钱 / 哪步踩坑 / 下一步投哪
- [ ] 判断：继续推广 / 调整 / 停止（用你写的停止条件）
- [ ] 优秀者报名"AI 倡导者储备池"（对接高级层八支柱）

> **行为改变三问（自我验收）**：① 我现在每周还在用吗？② 有同事因为我变了也开始用吗？③ 省的时间/钱我能拿出数字吗？三问全"是" = 真正落地。
