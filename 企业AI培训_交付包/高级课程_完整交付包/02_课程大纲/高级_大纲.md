# 高级 AI 培训 · 大纲（L4 规划治理层）

---

## 高级培训定位（交付说明）

本册对应五级能力塔的 **L4 规划治理层**，在整套企业 AI 培训体系中约占 **10% 课时**，是面向最高决策人群的战略层交付物。对象为 **CIO / CDO / 数字化负责人、厂长、战略与运营高管**——他们不需要会写代码、不需要会调模型，但需要能"算得清账、搭得起架构、推得动组织、守得住底线"。与初级（走进 AI、消除恐惧）、中级（用 AI 干真实场景）不同，高级聚焦"规划、治理、ROI 与组织级变革"。本册**刻意弱化"AI 工厂"的强指向**，不绑定某一类产线形态，而是以更宏观的"智能工厂梯度 + 技术-行业双线"适配各类制造企业。全册以 **GitHub 八支柱赋能操作系统**为组织落地核心，贯穿"政策螺旋（高级前瞻）"——讲清十五五 AI 与制造业融合趋势、数据/算法合规治理、企业 AI 治理体系怎么搭，全程不写代码，只讲战略、架构、治理、ROI 与组织。

# 第一部分 ·《高级 AI 培训 · 大纲》

> 层级定位：L4 规划治理层（高级 · 规划层）
> 目标人群：CIO / CDO / 数字化负责人、厂长、战略 / 运营高管
> 建议时长：**16–24 课时 + 2 天工作坊 + 标杆参访**
> 教学目标：能规划智能工厂、选型技术架构、算清 ROI、主导组织级 AI 赋能与变革

## H1 智能工厂梯度与战略（3 课时）

- 智能工厂三级梯度：**基础级 → 卓越级 → 领航级**（对标陕汽晋级路径）
- 国家"AI+制造"2027 目标锚点：**1000 个工业智能体 / 500 个典型场景 / 1000 家标杆企业**
- 梯度自评框架：数字化基础、数据贯通度、智能化深度、组织就绪度四维度
- 政策前瞻：十五五 AI 与制造业融合趋势、地方配套与标杆申报路径
- 标杆：陕汽"数字工匠 / 青蓝蓄能站"晋级样本；WEF 灯塔工厂（220+ 站点）梯度跃迁逻辑

## H2 技术架构选型（3 课时）

- **云-边-端**协同架构：哪些推理放云端、哪些下沉到产线边缘、哪些在终端
- **工业大模型 / 小模型**分工：通用大模型管认知协同，小模型（机理/统计模型）管确定性控制，"能用小模型就别上大模型"
- **数字孪生**：物理改动前先仿真验证
- **工业智能体**：感知-规划-行动-观察闭环，在制造场景的编排形态
- **5G + AI**：低时延、广连接对柔性产线与移动装备的支撑
- 双线视角：技术线讲架构原理，行业线讲"不同制造业态该选哪条路"

## H3 数据治理与首席数据官（2 课时）

- **数据管理能力成熟度**（DCMM 视角）：从初始级到优化级的跃迁路径
- **CDO 制度**：首席数据官的职责边界、向谁汇报、与 CIO 的分工
- **"模数共振"**：模型能力 × 数据资产的飞轮——数据供给质量决定智能上限
- 数据分类分级、主数据、数据资产入表与合规底座

## H4 AI 项目 ROI 与指标（3 课时）

- 制造核心指标：**OEE（可用率×性能×质量）**、**MTBF（平均无故障时间）**、**MTTR（平均修复时间）**、**不良率**、**单位能耗**
- 对标 GitHub 采纳指标：**MAU（月活用户）/ MEU（月活跃工程用户）**、用户分层（铁粉 / 偶尔 / 尝鲜）、业务影响度量
- ROI 测算框架：基线 → 实验 → 价值量化 → 危害/成本扣减 → 投资回收期
- 高管视角的"算不清账"破局：先建指标看板，再谈投入

## H5 组织级赋能操作系统（4 课时 · 核心模块）

改编自 GitHub 企业 AI 赋能 **八支柱**，作为组织落地的总操作系统：

1. **AI 倡导者**（Advocates）：从业务一线提拔、带动同伴的"火种"
2. **实践社区**（CoP）：跨部门的 AI 用法共享与答疑场
3. **L&D 学习发展**：把 AI 素养纳入人才供应链
4. **分级工具政策**（Tiered Tooling Policy）：按数据敏感度分级开放工具
5. **DRI 专职**（Directly Responsible Individual）：每个关键举措有唯一责任人
6. **高管背书**（Exec Sponsorship）：一把手持续发声、资源兜底
7. **数据驱动指标**（Metrics）：用 MAU/MEU、用户分层、业务影响看板度量
8. **负责任使用**（Responsible Use）：合规、安全、伦理的护栏

**三阶段落地节奏**：
- **0–30 天 奠基**：高管赞助 + DRI 就位 + 分级工具政策发布 + 指标基线 + 全员发布
- **30–90 天 起势**：倡导者计划 + 实践社区 + 资源中心 + 标杆秀（showcase）
- **持续规模化**：培训培训师（Train-the-Trainer）+ ROI 看板 + 定期问卷迭代

**指标看板**：采纳率 MAU/MEU、用户分层（铁粉 / 偶尔 / 尝鲜）、业务影响（OEE、停机、不良、能耗）

## H6 安全、伦理与治理（2 课时）

- 数据与模型的**分类分级**管理
- **幻觉防控**：人在回路、置信度、证据链，安全关键场景的处置权归人
- **AI 伦理**：公平、可解释、问责、不替代人的判断
- **合规**：数据/算法合规治理、企业 AI 治理体系搭建（对标 NIST AI RMF 映射-度量-管理四步）
- 政策前瞻：算法备案、数据出境、行业监管走向

## H7 沙盘推演与标杆参访（工作坊 2 天）

- 拆解 **陕汽**（数字工匠 / 青蓝蓄能站）与 **WEF 灯塔工厂** 的晋级逻辑与组织打法
- 2 天工作坊：用梯度自评表给本企业定位 → 用 ROI 模板算一个预测性维护项目回报 → 产出本企业 AI 规划与路线图沙盘
- 标杆参访（可选）：走进灯塔工厂 / 陕汽式标杆现场，看真实产线与组织协同

### 补充 · 建议时长与考核

| 项目 | 内容 |
|---|---|
| 建议总时长 | 16–24 课时（H1–H6 面授） + 2 天工作坊（H7） + 标杆参访（可选） |
