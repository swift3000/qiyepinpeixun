## 三、考核与认证

- 考核：规划方案（书面）+ 路线图答辩（高管评委组 ≥3/5 票）
- 认证：「AI 规划师」
- 随课交付物四件：学员手册 / 标杆案例集 / ROI 看板模板 / 八支柱工具包
- 结业产出：一份能上董事会的三年 AI 路线图

## 四、核心卖点（对外口径）

1. **四能力框架**：算得清账 · 搭得起架构 · 推得动组织 · 守得住底线 —— 对准高管四大困境
2. **核心模块 H5 八支柱**（GitHub 最佳实践改编）：AI 倡导者 / CoP / L&D / 分级工具政策 / DRI / 高管背书 / 数据驱动指标 / 负责任使用
3. **沙盘即答辩**：2 天 3 任务（梯度自评 / ROI 实算 / 路线图推演），结业即交付路线图
4. **合规前瞻**：十五五 / 算法备案 / 数据出境 —— 「政策定的是下限，你要的是上限」

## 五、PPT 结构（24 页）

封面 → 目录 → 定位 → H1 梯度（3 页）→ H2 架构（3 页）→ H3 数据治理（3 页）→ H4 ROI（3 页）→ H5 组织采纳（3 页，含八支柱核心页）→ H6 治理合规（2 页）→ H7 沙盘（1 页）→ 政策螺旋 → 考核认证 → 收尾

## 六、三级课程咬合（对外整体口径）

- 初级「为什么学」→ 中级「怎么拿资源」→ 高级「未来怎么变、怎么合规」
- 政策螺旋每转一圈，能力要求升一级；2027 锚点：约 1000 行业智能体 / 500 场景 / 1000 标杆试点
