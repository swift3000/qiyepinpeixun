# 分级工具政策模板（高级 · H5 支柱 4 · 通用企业版 V2.0）

> 用途：H5 八支柱第 4 根柱子的落地件——"按数据敏感度分级开放工具"的成文政策。0-30 天"奠基"阶段必须发布，它是全员发布的第一份文件。
> 版本：V2.0 ｜ 2026-09-02 ｜ 对齐《高级大纲》H5/H6 + 初级包 P47-48（数据红线/三档分级）+《AI 政策速查卡》合规红线节
> 对标：GitHub 分级工具政策（Tiered Tooling Policy）+ 等保数据分级惯例。

**怎么用（3 步）**：
1. 把本模板的"分级表"按自己企业的数据现实改一遍（哪些算高密，各部门不一样）。
2. DRI + 法务/合规过一遍红线条款（对照《AI 政策速查卡》：内容标识、拟人化互动、算法备案）。
3. 高管签发 + 全员发布；每季度复查一次（新工具上市是复查触发点）。

**两条铁律**：
- 政策管的是"什么数据能进什么工具"，**不是一刀切禁 AI**——防影子 AI 靠分级，不靠堵。
- 密级就高原则：拿不准的数据按高一档处理。

---

## 第一部分：数据三级 × 工具开放矩阵（核心表，照此改）

| 数据级 | 定义（举例） | 能用的工具 | 必须做的动作 |
|---|---|---|---|
| **L1 公开/脱敏** | 已公开的、或完全脱敏后不含任何可识别信息 | 所有已批准工具（含公有云大模型、网页版） | 用前确认脱敏到位（人名/客户名/数字替换） |
| **L2 内部敏感** | 内部经营数据、未公开产品、员工信息——不含客户合同与核心机密 | 公司采购的/私有化部署的工具；公有云工具须开企业版+签 DPA | 用前过一遍脱敏清单；输出留痕 |
| **L3 高密/红线** | 客户合同与报价、核心代码、财务原始账、身份证号/生物特征、未披露并购 | **禁止进任何外部 AI 工具**；只能用公司私有化部署且经安全评审的 | 用前 DRI 书面批准；用后登记 |

**脱敏清单（L1 用前自查，5 条）**：人名→代号 / 客户名→编号 / 具体金额→量级 / 日期→相对时间 / 联系方式→删除。5 条全过才能进公有云工具。

## 第二部分：工具准入清单（DRI 维护，每季度更新）

| 工具 | 类型 | 批准范围 | 批准条件 | 批准人 | 批准日期 | 复审日期 |
|---|---|---|---|---|---|---|
| （示例）DeepSeek 企业版 | 对话/写作 | L1+L2 | 签 DPA + 数据不留存条款 | | | |
| （示例）WorkBuddy | Agent 工作助理 | L1+L2 | 私有化部署 + 权限分级 | | | |
| （示例）某公有云大模型网页版 | 对话 | 仅 L1 | 脱敏清单 5 条全过 | | | |

**准入评审四问（新工具申请时逐条答）**：
1. 它的数据存哪？出境吗？
2. 用我们输入的内容训练吗？合同里写死"否"了吗？
3. 它生成内容的标识义务怎么满足（内容标识办法 2025-09-01 已施行）？
4. 出事后（泄露/编错）责任条款是谁担？

四问答不全 = 不批准，没有例外。

## 第三部分：违规处置（全员知道，执行不打折）

| 情形 | 处置 |
|---|---|
| L1 数据没脱敏就进公有云工具 | 首次：通报 + 重训；再犯：停用工具权限 1 个月 |
| L2 数据进未批准工具 | 立即停用 + DRI 评估是否构成泄露 + 当事人书面说明 |
| L3 数据进任何外部工具 | **24h 内报安全负责人**，按数据泄露事件走应急预案，当事人按制度处理 |
| 发现他人违规（举报） | 保护举报人，查实给奖励 |

**处置原则**：对事不对人，但 L3 零容忍——**出了泄露事件，先止血再定责，两件事都不许拖过 24 小时**。

## 第四部分：政策发布与复审（DRI 日历）

| 动作 | 时点 | 产出 |
|---|---|---|
| 首发 | 0-30 天奠基期，全员会发布 | 签字版政策 + 全员知悉确认（留档） |
| 季度复审 | 每季度 | 工具准入清单更新记录 |
| 事件触发复审 | 新工具上市 / 政策变化 / 发生违规事件 | 政策修订记录（版本号+1） |
| 年度培训 | 结合三档课（初级通识即 L1 全员版） | 培训签到 + 测试成绩 |

> 与合规的咬合：本政策是《AI 政策速查卡》里"合规红线"的执行载体——内容标识、拟人化互动服务（2026-07-15 施行）、算法备案三件事，落到具体工具上都由本政策的"准入四问"兜住。

## 常见坑（讲师点评用）

| 坑 | 症状 | 怎么救 |
|---|---|---|
| 一刀切全禁 | 员工转头全用私人账号（影子 AI 失控） | 回铁律 1：分级开放，L1 大胆用 |
| 清单永远不更新 | 批准工具 2024 年的，新工具没人管 | DRI 季度复审进日历，不审=失职 |
| 脱敏靠自觉 | 没人查，L2 数据直接贴进网页版 | 准入条件里写"输出留痕"，DRI 月度抽查 5 例 |
| 违规处置走过场 | 第一次就免了，制度没威信 | 处置表照执行，L3 零容忍写进高管会 |
