# 标杆案例集（高级 · 学员用 · 通用企业版 V2.0）

> 用途：H7 沙盘 Day1 AM"标杆拆解"的教材 + 学员回去拆自家标杆的样板。案例不是故事会——每个案例都按"晋级逻辑 + 组织打法"拆，拆完能抄出 3 个动作。
> 版本：V2.0 ｜ 2026-09-02 ｜ 对齐《高级大纲》H1/H7 + 路线图模板第一/七部分
> 用法：讲师拆 1 个示范（案例 A），学员用同一张表拆自己选定的标杆（附空白表），沙盘答辩时交上来。

**标杆选型三问（先定标，再拆解）**：
1. 它比我强在哪一级？（对照 H1 四级：起步/扩展/规模化/智能）
2. 它的起点和我像不像？（行业不同没关系，"组织起点"像才有参考性）
3. 它踩过的坑我能不能避开？（只拆"它做对的"是幸存者偏差，必须连坑一起拆）

---

## 案例 A（示范拆解）：WEF 灯塔工厂网络的共性逻辑

**它是什么**：世界经济论坛"灯塔网络"（Lighthouse Network）——全球最先进制造与供应链工厂的认证网络，2026 年已覆盖 220+ 站点、40+ 国家，被称为"全球工业 4.0 的奥林匹克"。

**怎么拆（照这张表，学员抄格式）**：

| 拆解维度 | 内容（公开信息口径） |
|---|---|
| 晋级路径 | 共性是"从一个痛点场景切入 → 跑通一个灯塔点 → 复制成网络"，不是先建全厂数字化 |
| 组织打法 | ① 一把手工程（工厂总经理亲自挂帅）② 跨职能小队（IT+OT+一线班组长混编）③ 先量化基线再上技术 |
| 关键数字（公开口径） | 认证工厂普遍报告：缺陷率下降 10-30%、交付周期缩短 15-40%、人均产出提升 10%+（不同站点差异大，取其区间不取单点） |
| 踩过的坑（公开复盘口径） | ① 先买设备后理流程 = 钱花了流程没变 ② 数据不通：设备联网了但数据还是各系统孤岛 ③ 一线不参与：班组长不参与设计，上线就遭软抵制 |
| 可抄的 3 个动作 | ① 选 1 个最痛场景先跑通再扩 ② 混编小队（别只让 IT 干）③ 上线前先定"哪个数字算成" |

**讲师收口句**：灯塔不是设备最贵的工厂，是组织操作系统最顺的工厂——数据通、人才密、决策快。设备会折旧，操作系统不会。

## 案例 B（示范拆解）：GitHub——90% 员工用 AI 是怎么来的

**它是什么**：微软旗下代码协作平台。公开分享（GitHub 官方与行业报告）：员工中约 90% 日常使用 AI 辅助，AI 贡献了相当比例的代码变更，且公司把它当成"产品 + 内部实践"一体推进。

| 拆解维度 | 内容（公开信息口径） |
|---|---|
| 晋级路径 | 不是"先培训后使用"，是**先让员工用上自己公司的产品**（dogfooding），再沉淀成内部规范 |
| 组织打法 | ① 工具是自家产品，使用零门槛 ② 内部沉淀提示词/工作流模板供全员抄 ③ 安全侧同步做分级（什么代码能进 AI、什么不能）——工具政策和使用文化一起长 |
| 关键数字（公开口径） | ~90% 员工日常使用；公司公开报告 AI 参与的部分代码变更可在数小时内完成原本数天的工作（取其趋势，不抠单点） |
| 踩过的坑（公开讨论口径） | ① 早期滥用导致代码质量波动 → 后来强制"人终审"文化 ② 敏感代码外泄风险 → 分级工具政策跟进 ③ 只算"写了多少"不算"返工多少" → 指标体系改成净产出 |
| 可抄的 3 个动作 | ① 挑"自家天天用的工具"先推（员工已有感情）② 模板先行：抄得会再谈创新 ③ 指标算净产出（减去返工），不算毛产出 |

**讲师收口句**：GitHub 的 90% 不是培训部训出来的，是"工具好用 + 有模板抄 + 有底线管"三件事一起转出来的。你回去找你的"自家产品"——不一定是软件，可以是你公司里已经跑熟的一个 AI 场景。

## 案例 C（跨行业对照，讲师口播用，1 分钟一个）

| 标杆 | 行业 | 一句话拆法（晋级逻辑） | 可抄 1 个动作 |
|---|---|---|---|
| WEF 灯塔工厂（制造类站点） | 制造 | 单点跑通 → 网络复制 | 先定"哪个数字算成"再上技术 |
| GitHub | 软件 | 自家产品 dogfooding + 分级政策同步 | 模板先行，抄得会再创新 |
| 国内"人工智能+"行业试点（国发〔2025〕11 号配套） | 各行业 | 政策锚点卡位：行业智能体/典型场景/标杆企业三条申报线 | 把试点申报写进 30-90 天计划，政策红利 = 免费的钱 |
| 陕汽（数字工匠 + 青蓝蓄能站）〔制造加开〕 | 制造 | 技能传承 + AI 辅助并行，老师傅经验数字化 | 让老师傅当倡导者（人+AI 双传承） |
| 西门子 Senseye〔制造加开〕 | 制造 | 设备异常预测，从"坏了再修"到"坏前知道" | 传感器数据先积累 6 个月再谈预测 |
| 博世〔制造加开〕 | 制造 | 集团级 AI 平台 + 工厂级场景落地分层 | 集团出平台，工厂出场景，各干各的活 |

> 标注〔制造加开〕的案例，通用课上 1 分钟带过即可；制造客户加开《行业案例包·制造业》时逐条展开（279 号政策 + 陕汽完整样本在该包内）。

## 讲师使用提示

- 示范只拆 1 个（案例 A 或 B 二选一，看学员行业偏制造还是偏知识型），剩下让学员拆。
- 数字纪律：案例里的数字**必须带来源口径**（年报/官方发布/行业报告），教高管"引数字要带出处"——这是路线图答辩的基本功。
- 防幸存者偏差：每次拆标杆强制"踩过的坑"一栏，空着不算拆完。
