## 1. 设计系统（沿用 PPT1）

- 画布 1280×720（16:9）；内容页三区：A 标题块（0-120px）/ B 内容区（120-660px）/ C 页脚条（660-720px）。
- 色板：主 #1E3A8A / 辅 #06B6D4 / 强调 #F59E0B / 文本 #1A1A1A / 中性 #64748B / 浅底 #F5F8FC。
- 字体：中文 思源黑体/PingFang SC；西文数字 Space Grotesk/Inter。层级字号与 PPT1 一致（封面 72 / 扉页大字 56 / 主标题 34 / 卡题 24 / 正文 20 / 页脚 14）。
- 封面/扉页/结束页：深蓝底或全幅图 + 蒙版（复用 PPT1 底图 hero_cover / 神经网络 / 机器人 / 盾牌等资产，经 rels 共享，不重复嵌图）。

## 4. 构建工艺（python-pptx 克隆，可复跑）

- 底版：`../通用基础_PPT1/通用基础_PPT1.pptx`（33 页真源）。
- 工艺：`add_slide(donor.slide_layout)` → 清空 spTree → 深拷贝 donor 子元素（跳过 nvGrpSpPr/grpSpPr）→ 复制 p:bg → 复制 rels（图片 part 共享，rId 变化则全 XML 重映射）→ 按 shape 索引文本手术（保留首段 pPr + 首 run rPr，`\n` 拆多段）→ 删减行（P2 目录删 3 行 / P26 清单删 4 行）→ 全局页脚手术 → 删原 33 页（只删克隆前记录的 sldIdLst 条目）。
- 脚本：`build_ppt2.py`（本目录，含 DONOR 映射 + SPEC 全量文本，可复跑重建）。
- 校验（每次构建后跑）：33 页；无 PPT1 残留词（家族树/豆包/DeepSeek/上下文窗口/CHAPTER SIX 等）；页码对位；无页脚页 = {1,3,10,17,25,33}；图片 shape 64 张；关键页抽查（P8 项目库/P13 RAG/P29 百分制/P32 组模式）。
