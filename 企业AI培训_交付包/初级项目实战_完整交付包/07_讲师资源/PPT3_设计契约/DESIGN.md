# 实战项目工作坊 · PPT3 设计文档（DESIGN.md）

> 版本：v1.0（2026-08-31）。PPT3 与 PPT1 v2 / PPT2 **共用同一设计系统**（画布/色板/字体/密度门禁/配图），不新造视觉。本文档记录 PPT3 的页型分布、donor 克隆映射、文本手术工艺与页脚口径。

## 1. 设计系统（沿用 PPT1 v2）

- 画布 1280×720（16:9）；内容页三区：A 标题块（0-120px）/ B 内容区（120-660px）/ C 页脚条（660-720px）。
- 色板：主 #1E3A8A / 辅 #06B6D4 / 强调 #F59E0B / 文本 #1A1A1A / 中性 #64748B / 浅底 #F5F8FC。
- 字体：中文 思源黑体/PingFang SC；西文数字 Space Grotesk/Inter。层级字号与 PPT1 一致。
- PPT1 v2 的版式文字多在 **GROUP 分组**内（非扁平 shape），文本定位一律用「递归进 group + 整框文本精确匹配」，不用 shape 索引。

## 2. 页脚口径

- 内容页左："实战项目执行手册" 14px #64748B；右："NN / 33"。
- 无页脚页：P1 封面、P33 结束（donor 即无页码框）。内容页 P2-P32 共 31 页全部带页脚，页码与页序一一对应（构建脚本全局手术保证）。

## 5. 构建工艺（python-pptx 克隆，可复跑）

- 底版（donor 真源）：`初级课程_完整交付包/03_PPT课件/通用基础_PPT1_v2.pptx`（38 页）。
- 工艺：`add_slide(donor.slide_layout)` → 清空 spTree → 深拷贝 donor 子元素（跳过 nvGrpSpPr/grpSpPr）→ 复制 p:bg → 复制 rels（rId 变化则全 XML 重映射）→ **递归进 group 收集文本框，整框精确匹配替换（每个 old 断言唯一命中，防误伤）** → 全局页脚手术（'通用 AI 基础 · 初级'→'实战项目执行手册' + 页码 NN/33）→ 删原 38 页（**克隆前先记录 orig_sldIds，只删这批**——PPT2 首跑 0 页事故的教训）。
- 文本替换设两阶段：先收集全部命中再统一应用，`set_text` 保留首段 pPr + 首 run rPr，`\n` 拆多段。
- 脚本：`build_ppt3.py`（本目录；SRC/OUT 按脚本位置定位 parents[3]，可复跑重建）。
- 校验（每次构建后跑）：33 页；donor 残留词为 0（提示词五要素/聊天大模型/红线一/通用 AI 基础/岗位场景/新手三步/高校·/学校·/企业·/通用·/五要素/知识库：把/Agent 与 Copilot 等）；页脚 31 页 + 页码对位；26 张卡各 30 个文本框。
