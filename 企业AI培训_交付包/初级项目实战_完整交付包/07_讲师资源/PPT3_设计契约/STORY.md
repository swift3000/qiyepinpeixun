## ① 意图对齐（5 问）

- **目标受众**：讲师（主）+ 学员（看总览/卡面）。适用三天正式班：Day 1 通识（PPT1）→ Day 2-3 立项与实战（PPT2 + PPT3）。
- **核心目标**：讲师翻开 PPT3 就能——① 照 P2 排三天课；② 照 P4 点齐六样环境；③ 照 P5 定选型；④ 翻到 P6-P31 任一项目卡，照着给学员**出题**（三步 = 干到哪，A-E 行 = 目标/交付/验收/辅导/材料）；⑤ 照 P32 验收收工。辅导细节不塞进 PPT，留在项目包详案（巡场时拉出来）。
- **PPT 长度**：33 页 = 5 张结构页 + 26 张项目卡 + 验收页 + 结束页。
- **视觉调性**：与 PPT1 v2 / PPT2 完全同一设计系统（克隆同源），讲师手册感 = 信息密度略高、每页可独立当教案用。
- **内容边界**：必讲——三天总览、选题五步、环境准备六样、选型规则、26 包执行卡、验收五步；不讲——方法论细节（PPT2 已讲）、项目包全文（详案不进 PPT，只进辅导）。

## ② 骨架（33 页）

- **结构页（5）**：P2 三天课总览 / P3 选题五步 / P4 环境准备六样 / P5 项目选型规则
- **项目卡（26）**：P6-P31，顺序 = 包号序（A1-A3 → B1-C2 → D1-D15 → E1-E3），一页一包
- **收尾页（2）**：P32 验收与路演五步 / P33 结束

**项目卡版式**（donor P23「三步上手 + 岗位场景」改造）：
- 顶部：`包号 · 项目名` + 一句话副题
- 中部：3 个 STEP（包内执行三步）
- 五行（A-E 字母芯片复用）：**A 目标 / B 交付 / C 验收 / D 辅导 / E 材料**
- 右下信息块：时长 + 难度/模式（★数 · 个人/个人组/仅组）

**卡面文字纪律**（保证单页不溢出）：标题 ≤16 字、副题 ≤11 字、步骤标 ≤4 字、步骤述 ≤12 字、A/B 行述 ≤25 字、C/D 行述 ≤28 字、E 行述 ≤22 字。
