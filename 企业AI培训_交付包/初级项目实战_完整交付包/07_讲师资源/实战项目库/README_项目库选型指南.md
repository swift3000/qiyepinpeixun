# AI 项目库 · 选型指南（26 个独立项目包）

> 定位：《实战项目工作坊》（初级第二篇 PPT）的**选题来源**。实战包为通用行业包（企业/高校/学校），与制造业无关。
> 用法：讲师开课前从 26 包里**挑 1-2 包穿插**进课；学员按包落地（征集单预填 → 立项书预填 → 执行 → 验收）。
> 每个包独立成文件，可单独用于课后延伸/自主练习，不依赖课程。
> 版本：v1.1（2026-08-27）——扩充至 26 包：智能体类补齐 7 包（客服/网页收集/文档批处理/数据分析/检索调研/多Agent）、工具·自动化类补齐 3 包（定时报表/OCR 台账/表单通知流），对标 2025-2026 主流落地形态。

## 二、项目包结构（每包 5 件）

1. **项目卡**：一句话 / 交付物 / 核心能力 / 难度 / 预计时长
2. **征集单预填**：项目名 + 真实任务描述 + 三条件自检（小/高频/可验证）
3. **立项书预填**：六字段（背景/目标/输入数据/AI 任务拆解/验收标准/ROI 预估）
4. **验收标准**：通用 5 条 + 本包专项检查
5. **讲师要点**：巡场卡点与解法、红线提示、点评素材 + 学员材料清单

## 三、选型规则（讲师挑着穿插）

1. **默认组合（个人班）**：1 个入门包（A1 或 B1）+ 1 个流行深化包（D1 知识库 RAG）——一低一高，对照出"项目能做大"的感觉。
2. **智能体班（推荐）**：深化包从智能体 7 包里挑——通用岗首选 D7 客服问答（最主流、最好演示）或 D8 网页收集；文档多的岗位选 D9；数据岗选 D10；要"调研"味道选 D11。
3. **工具·自动化班**：深化包换 D3/D12/D14（定时报表/OCR 台账/表单通知），突出"数字员工"概念。
4. **组模式（PMP）**：组项目从 L4（E1-E3）、D15（多 Agent 协作）或 D 档重头包（D1/D2/D8）挑，3-4 人/组（导演/产品/执行/QA）。
5. **纪律**：一次课穿插包 ≤ 2 个；所有包遵守"小、高频、可验证"；L2 网页类 = 单页 HTML（不接真后端）；L4 = 原型级（非上线产品）；包内示例只是梯子，学员必须换成自己岗位的材料才成为自己的项目。

## 四、穿插操作（5 步）

1. **选型**（开课前 1 周）：按上节规则定包，把选中包的"征集单预填"发学员对照填。
2. **收集**：任务征集单回收，讲师按三条件逐个筛（不合格当场换包内示例方向）。
3. **课内**：按 PPT2 四段节奏走（选题 40' → 立项 45' → 执行 80' → 验收 45'），立项环节发选中包的"立项书预填"。
4. **验收**：用选中包的"验收标准"+《项目验收清单》当场打分（百分制四维）。
5. **延伸**（可选）：未选中的包作为课后练习清单发给学员，注明"自主项目不计结业"。
