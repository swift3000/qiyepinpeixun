# 项目包 D15 · 多 Agent 协作（L3 能力深化类）

> 实战项目库 · 独立项目包 ｜ 档位 L3（智能体类）｜ 模式：**仅组模式（PMP）** ｜ 建议 2-3h（含验收）
> 多智能体协作是 2026 智能体编排的主流方向：一个任务拆给 2-3 个各司其职的 Agent 接力跑，人当总导演。

## 一、项目卡

- 一句话：3 个 Agent 接力干 1 件事：调研 Agent 找料 → 写作 Agent 成稿 → 质检 Agent 挑错，人当总导演。
- 交付物：1 份成品（如 1 页调研报告/1 份活动通告）+ 3 个 Agent 的任务书 + 交接记录（每棒之间传了什么）。
- 核心 AI 能力：多智能体编排（角色分工 + 接力 + 质检回路）。
- 难度：★★★★☆ ｜ 2-3h ｜ 前置建议：组内至少 1 人做过 D2 任务 Agent。

## 二、征集单（预填示例）

- 项目名：调研报告多 Agent 流水线
- 组内真实任务：每月要给领导 1 份"XX 动态"简报，人工搜+写+校 3 个环节约 3 小时
- 三条件自检：小（1 次 1 页 √）/ 高频（每月 √）/ 可验证（结论有源、质检清单全过 √）

## 三、立项书预填（六字段，组级）

- 背景：简报"搜+写+校"三环节串行靠人，费时且质量看状态
- 目标：调研/写作/质检 3 个 Agent 接力，1 次产出 1 页带源简报；人只做总导演（派活+终审）
- 输入数据：主题 1 个 + 必答题 3 个；质检清单 5 条（有源/无编造/口径统一/格式齐/结论可执行）
- AI 任务拆解：① 给 3 个 Agent 各写 1 页任务书（职责+输入+输出格式）→ ② 第 1 棒调研出料 → ③ 第 2 棒成稿 → ④ 第 3 棒按清单质检并回传修改 → ⑤ 人终审
- 验收标准：成品 1 页达标；3 份任务书齐全；交接记录能看到每棒输入输出；质检清单 5 条全过
- ROI 预估：3h → 1h（人只花派活+终审的时间）

## 四、验收标准

通用 5 条同上 + 组模式加"全组三件套齐"。
本包专项：
- 3 个 Agent 任务书（职责/输入/输出格式各 1 页，合计 3 页）；
- 交接记录：第 1 棒产出 → 第 2 棒输入（截图或文件，能对上）；
- 质检 Agent 真的挑过 ≥1 处问题并有修改痕迹（全过零问题 = 质检没干活，打回）；
- 导演手册：组里谁当导演、每棒谁盯（PMP 角色到位）。

## 五、讲师要点（导演手册）

- 卡点① 三棒同时开跑 → 纪律：上一棒产出验收后才开下一棒（G2 关卡思想用到 Agent 间）。
- 卡点② 任务书写成一句话 → 每份任务书必须含"输入/输出格式/不许做什么"三块。
- 卡点③ 质检 Agent 变成盖章 → 任务书写死"至少挑 1 处，挑不出要说明为什么"。
- 红线：同 D11（只收公开信息，主题涉密当场换）。
- 点评素材：多 Agent 是智能体编排的当前主流（行业里"多智能体工厂"已落地 20+ 智能体串联）；今天 3 棒接力，中级课做 5 棒 + 定时触发。

## 六、组材料清单（开课前 3 天准备）

1. 主题 1 个 + 必答题 3 个（全组统一）
2. 质检清单 5 条（全组统一，课前讲师过一遍）
3. 3 份 Agent 任务书草稿（组内分工各写 1 份，课上改）
