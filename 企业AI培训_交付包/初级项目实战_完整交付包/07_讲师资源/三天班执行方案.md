# 三天班执行方案（正式授课版 · 讲师手册）

> 定位：三天正式班的「组织总纲」——讲师照着排课、备环境、出题、巡场辅导、验收发证。
> 课表：第 1 天懂 AI（PPT1）；第 2 天立项 + 执行一（PPT2 + PPT3）；第 3 天执行二 + 验收路演（PPT2 + PPT3）。
> 三件套课程资产：PPT1（**企业版 v3.0，49 页通识**）+ PPT2（33 页工作坊方法论）+ **PPT3 执行手册（33 页 = 26 张项目卡，一页一包）**。
> 版本：v1.0（2026-08-31）｜ 配套：`实战项目_执行手册_PPT3.pptx`、`实战项目库/` 26 包

## 一、一句话设计

**Day 1 懂 AI（PPT1），Day 2-3 干成事（PPT2 + PPT3 + 项目包）——结业 = 验收通过一个本人岗位的真实项目。**

- 讲师的角色：第 1 天是「老师」，第 2-3 天是「项目经理 + 巡场教练」——按 PPT3 项目卡给学员**出题**，卡壳时把对应**项目包的详案**（讲师要点节）拉出来辅导。
- 学员的产出：三件套 = 交付物（真实文件）+ 一页立项书 + 验收清单签字。

## 四、环境准备：六样点齐（时间轴版）

> 口诀：**账号、网络、材料，三样最容易翻车——全做在课前 3 天。** 对照 PPT3 P5 六卡逐样打勾。

### T-7（开课前 1 周）

- [ ] 定人数、班型（个人/组）、岗位结构 → **挑包**（选型指南 5 条规则：默认 A1 + D1 一低一高；智能体班 D7/D8；组班 E1-E3/D15；一次课穿插 ≤ 2 包）
- [ ] 《任务征集单》人手一份发出（每人 1 个本人岗位真实任务）
- [ ] WorkBuddy 账号池采购：数量 = 学员数 × 1.2（20% 备用防掉线）
- [ ] 订教室：每人 1 电脑、投影、网络 ≥ 50Mbps、插线板、白板
- [ ] 演示数据：按选中包各备 1 套脱敏演示材料（如 A1 = 2 周周报样本）

### T-3（开课前 3 天）

- [ ] 《学员课前准备单》发出，催收三件事：账号能登录 / 材料进资料库 / 征集单交上来
- [ ] 账号池逐个登录测试（登录态 / 额度 / 资料库功能）
- [ ] 学员材料入库：讲师按入库清单**逐份过脱敏**（三删：人名电话 / 账号密码 / 涉密数据）

## 五、选题与分组：组织流程

### 选题五步（PPT3 P4）

1. **发征集单**（T-7，课前 3 天截止）：人手一份，填本人岗位真实任务
2. **学员选题**（D2 上午 20min）：征集单任务优先；没有就 26 包里挑离岗位最近的 1 包，换成自己的材料
3. **讲师筛查**：三条件过筛——够小？高频？可验证？三条全中才立项，不合格当场换（换题不丢人，空题才丢人）
4. **分组结对**：组班 3-4 人/组四角色到人；个人班一人一项目、邻座互援
5. **立项冻结**：六字段立项书填齐 + G1 通过 → 冻结，不许再改题

### 出题三不（讲师按 PPT3 项目卡派任务时）

1. **不给真实公司数据**——只用脱敏 / 代号材料（红线）
2. **不照抄包内示例**——交付物与包内示例雷同 = 验收不通过（换成自己的材料才叫自己的项目）
3. **不放大范围**——只做卡上写的（E 行材料清单为界），多做的记入课后延伸清单

### 组班组织（PMP 四角色，3-4 人/组）

| 角色 | 职责 | 验收时 |
|---|---|---|
| 导演 | 总负责、卡时间、断点记录 | 主讲 2 分钟路演 |
| 产品 | 页面清单、口径、验收标准 | 亮立项书 |
| 执行 | 提示词、生成、迭代 | 现场演示交付物 |
| QA | 抽查数字、查脱敏、跑验收预检 | 过 5 条清单 |

- 组选题：E1-E3 / D15 或 D 档重头包（D1/D2/D8）；关卡 G1 立项 / G2 半天 / G3 验收预检
- 评分：四维 40/25/15/20 + 互评 10 分（计入「呈现协作」项参考）；小组结业 = 全组三件套齐

## 六、辅导方法：拉详案辅导

**项目包 = 讲师辅导详案**。PPT3 项目卡上只有短句（课上派任务用），卡壳细节全在项目包「五、讲师要点」里——巡场时按卡号翻对应包。

### 巡场两轮 + 一预检

| 轮次 | 时机 | 只看一件事 | 卡壳动作 |
|---|---|---|---|
| 第一轮 | 执行 30min 后 | **动没动**：选题清楚没？材料进库没？第一句提示词写没写？ | 拉项目包「讲师要点·常见卡点」，当场给解法 |
| 第二轮 | 执行 60min 后 | **对不对**：交付物方向对没？红线守没守（脱敏）？ | 拉项目包「立项书预填 + 验收标准」逐条对，拉回卡上范围 |
| 预检 | 收工前 30min | **完没完**：验收 5 条自检 + 断点记录齐不齐 | 不齐的当场定「明天第一件事」3 件 |

### 点评素材（每组至少 2 句，收工和路演用）

- 每组 1 句好的（从断点记录 / 三版迭代截图里找真实证据）
- 每组 1 句常见错（项目包「讲师要点·点评素材」现成有）
- 收口统一口径：**验收对事不对人**——不通过当场给最小可行降级路径（任务砍小 50%），不让人空手下课

## 七、验收与路演口径（D3 下午）

- 5 步收工（PPT3 P34）：查交付物 → 查立项书 → 现场演示 → 评分点评 → 发三件套
- 三档判定：≥80 过 ｜ 60-79 待修（7 天窗口补验收）｜ <60 不通过（降级重跑或记下期复训）
- **红线优先**：脱敏不过 = 红线项 0 分 + 项目不通过，无商量空间
- **数字必抽**：每桌至少抽 1 处数字回源——这是全场「人做终审」的示范动作
- 留证据：通过名单 + 清单拍照存档 = 结业记录
