## 三、班型与时间轴（单开半天版 3h 基准）

| 段 | 时长 | 内容 |
|---|---|---|
| 第 1 章 选题 | 40min | 项目三件套 / 好选题三条件 / 反例 / 项目库 26 包 / 现场选题 20min |
| 第 2 章 立项 | 45min | 立项书六字段 / 两范例 / 现场填 15min + 同桌互评 10min |
| 第 3 章 执行 | 80min | 拆 3-5 步 / 派任务 / 三版迭代 / 人终审 / 断点 / 现场执行 60min |
| 第 4 章 验收 | 45min | 验收 5 条 / ROI / 路演 20min / 点评结业 10min |

四种班型：

| 班型 | 时长 | 课表 | 课程资产 |
|---|---|---|---|
| 单开半天版 | 3h | 上表四段（选题 40'/立项 45'/执行 80'/验收 45'） | PPT2 |
| 一天版合并 | 7h | PPT1 压缩 4.5h + 工作坊 2h | PPT1 + PPT2 |
| 一天半版 | 10h | PPT1 5h + 工作坊 5h（重产出） | PPT1 + PPT2 |
| **三天正式班** | 3×6h | **D1 通识全讲 / D2 立项+执行一 / D3 执行二+验收路演**（逐时程见《三天班执行方案》） | PPT1 + PPT2 + **PPT3** |

组模式 PMP（3-4 人、导演/产品/执行/QA、关卡 G1-G3、百分制评分）为可选班型，三天班默认走组模式或个人一人一项目。

## 四、前置条件（开课前落实，缺一不可）

1. 任务征集单已回收（每人 1 个本人岗位真实任务，开课前 1 周）
2. WorkBuddy 账号池：每人 1 个，开课前 1 天联调（登录态/额度/资料库）
3. 学员已把脱敏任务材料存入 WorkBuddy 资料库（开课前 3 天，按《学员课前准备单》）

## 五、考核与结业

- 结业标准 = **项目验收通过**：交付物（文件）+ 一页立项书 + 验收清单 5 条勾满（三件套）
- 评分：百分制四维——交付物 40 / 过程规范 25 / 红线合规 15 / 呈现协作 20
- 判定：≥80 通过 ｜ 60-79 待修（7 天补验收）｜ <60 不通过；小组结业 = 全组三件套齐
- 红线：脱敏数据 / 批准工具 / 人做终审——出现涉密信息 = 红线项 0 分且项目不通过
