# 项目验收清单（讲师用 · 课内当场验收）

> 用途：《实战项目工作坊》收尾环节，讲师逐人过 5 条清单，当场定"验收通过 / 待修 / 不通过"。
> 验收通过 = 结业依据（交付物 + 一页立项书 + 本清单签字）。
> 配套：《实战项目_大纲_PPT2》v1.0 ｜ 版本：v1.0（2026-08-27）

## 验收 5 条（逐条打勾，不通过就说清差在哪）

| # | 检查项 | 通过？ | 备注（差在哪） |
|---|---|---|---|
| 1 | **交付物是真实文件**：能打开、能用，不是截图、不是聊天记录 | □ | |
| 2 | **数字/人名/事实已抽查**：抽查 ≥3 处与源材料一致，无编造（幻觉） | □ | |
| 3 | **脱敏红线过关**：交付物和过程里没有真实人名 / 客户 / 金额 / 内部编号 | □ | |
| 4 | **立项书六字段齐**：背景/目标/输入/拆解/验收标准/ROI 都填了，目标可验证 | □ | |
| 5 | **过程能接手**：同事拿到"一句话任务 + 材料清单"，能照着重复跑一遍 | □ | |

## 判定口径

| 结果 | 标准 | 处理 |
|---|---|---|
| ✅ 验收通过 | 5 条全过 | 结业三件套齐（交付物 + 立项书 + 本清单签字） |
| 🔧 待修 | 差 1 条，且 7 天内可修 | 给明确修改点，7 天内线上补验收 |
| ❌ 不通过 | 差 2 条以上 | 任务太大/走偏——降级为"简化版目标"重跑，或记入下期复训 |

> 原则：**验收对事不对人**。不通过的学员当场给一条"最小可行降级路径"（把任务再砍小 50%），不让人空手下课。

## 现场验收节奏（每人 3 分钟）

1. 学员 60 秒：演示交付物（打开文件指给人看）
2. 讲师 60 秒：按 5 条过一遍，抽查 1 处数字
3. 全体 60 秒：一句话点评"最有用的一个点"（互评，讲师收口）
4. 讲师签字 + 盖"验收通过"标记（清单第 5 条通过后签）

## 讲师备忘

- **红线优先**：第 3 条（脱敏）不通过 = 直接不通过，无商量空间。
- **数字必抽**：第 2 条必须真的抽查，哪怕只抽 1 处——这是全场"人做终审"的示范动作。
- **不追求完美**：初级项目的通过线是"能重复跑、有人把关"，不是"产品级交付"。学员交出来的东西糙一点没关系。
- **留证据**：通过名单 + 清单拍照存档，作为结业记录；不通过的修改点写进备注栏。
