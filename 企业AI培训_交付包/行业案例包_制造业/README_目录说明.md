# 行业案例包 · 制造业（加开件，V1.0 制造版存档 + 案例政策速查）

> 定位：**通用主课（中级/高级 V2.0）的制造业加开件**。通用课讲方法论，本包提供制造业专属场景、案例、数据活动包与政策详解，供**面向制造业客户**时叠加使用。
> 版本：V1.0（2026-09-02 从通用版 V2.0 改造前的制造版原文提取，git baseline 8d6bfd1）
> 铁律：本包**只增不改**通用课——通用课主线不引用本包内容；本包在通用课对应模块"加开"行业场景与案例。

## 一、什么时候用本包

| 客户类型 | 用哪个包 |
|---|---|
| 金融/零售/政企/服务业 | 只用中级/高级 V2.0 通用课，**不用本包** |
| 制造业（离散/流程/设备） | 通用课 V2.0 主线 + **本包加开**（对应模块换制造场景/案例/数据） |
| 制造业投标 | 通用课 + 本包的陕汽/西门子/博世铁案 + 279 号政策详解 |

## 四、加开操作建议

1. **整模块加开**：制造客户整班时，用本包制造版讲义替换通用版对应模块（如 M2 直接讲预测维护），通用版作底稿。
2. **局部加开**：通用客户但带部分制造场景，在通用版模块后"加一节"制造案例（如 M3 通用审核后加"制造业视觉质检案例"）。
3. **只借案例**：投标/汇报时只引本包案例与政策速查卡，不动课程主体。
