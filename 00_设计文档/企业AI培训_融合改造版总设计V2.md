## 一、设计者的底层判断（先说人话）

做企业 AI 培训，最容易犯的错是**一上来就讲技术**。客户是车间主任、采购、质量、设备、办公文员——他们连"大模型"和"搜索引擎"都分不清。所以这套体系的第一铁律：

> **基础是大头，认知是入口，技术是手段，行业是落点。**  
> 客户先"走进 AI、不害怕 AI"，再"懂 AI、会聊 AI"，最后才"用 AI 解决自己的事"。

哈佛、MIT、Andrew Ng 的顶级课都印证了一件事：**非技术人群学 AI，概念先行、代码靠后**。所以我们把所有"写 Python 建模型"的原版内容，一律改成"懂场景、用工具、做设计"。

## 三、五级能力渐进塔（分层核心）

按你说的"分成不同层、按部就班逐渐深入"，我设计了**五级塔**。基础（L0+L1）占整个培训 **60% 的课时和篇幅**——因为客户是大头、基础是大头。

```
        L4 规划治理层  ·  AI战略规划（高管/数字化负责人）   ← 高级交付（弱化"AI工厂"强指向，更宏观适配各类制造企业）
       ─────────────────────────────────────────
        L3 场景应用层  ·  用AI解决真问题（岗位实战）       ←
       ─────────────────────────────────────────
        L2 行业认知层  ·  看AI在制造业（政策+标杆+场景地图）← 中级交付
       ─────────────────────────────────────────
        L1 基础通识层  ·  懂AI（名词/工具/提示词/安全）    ←
       ─────────────────────────────────────────
        L0 破冰启蒙层  ·  走进AI（是什么/能/不能/我已在用）← 初级交付（最重）
```

| 层级     | 名称   | 关键词               | 课时权重    | 对应原版素材（融合来源）                                                             |
| ------ | ---- | ----------------- | ------- | ------------------------------------------------------------------------ |
| **L0** | 破冰启蒙 | 去神秘化、不恐惧          | **25%** | MIT AI 101 + 赫尔辛基 Elements of AI + 陕汽"去神秘化"手法                            |
| **L1** | 基础通识 | 懂名词、会工具、写好提示词     | **35%** | Andrew Ng《AI for Everyone》(W1-W2) + 微软 generative-ai-for-beginners(概念部分) |
| **L2** | 行业认知 | 政策、标杆、制造业场景地图     | 15%     | 国发〔2025〕11号 / 工信部279号 / 陕汽案例 + 全球灯塔工厂                                    |
| **L3** | 场景应用 | 视觉质检/预测维护/知识库/RAG | 15%     | tertiarycourses 课件包(10活动) + Industrial-AI(8节)                            |
| **L4** | 规划治理 | 智能工厂梯度/架构/ROI/组织  | 10%     | KAIST 智能制造 + 哈佛CS50概念层 + 微软Foundation Models + GitHub八支柱                 |

> 说明：L0+L1 = 初级（占60%，大头）；L2+L3 = 中级（30%）；L4 = 高级（10%）。三档对外交付、五级对内教学，一套体系两副面孔。

## 三·补：政策螺旋强化机制（关键设计修订）

用户明确要求：**政策解读不只放在中级，要贯穿三级、每次讲都强化、深度递进**——这是更符合"技术小白从政策入门"与成人培训螺旋上升逻辑的设计。

- **初级（L0+L1）**：政策作为"为什么学 AI"的入口——国家"人工智能+"行动、十五五规划对 AI 的部署、制造业相关行业政策，讲清"大势所趋、与个人/企业有什么关系"，不深抠条文。
- **中级（L2+L3）**：政策深读——对照《AI+制造》专项行动，看国家要什么、补贴/标杆/试点怎么拿、地方配套，作为场景落地的指挥棒。
- **高级（L4）**：政策前瞻——十五五 AI 与制造业融合趋势、数据/算法合规治理、企业 AI 治理体系怎么搭。

> 螺旋原则：同一政策话题在三级中反复出现，但视角从「是什么 / 对我有啥用」→「怎么用 / 怎么拿资源」→「未来怎么变 / 怎么合规」，逐层加深。

## 四、三级交付 × 双线设计（讲技术，也讲行业）

每一级都跑**两条线**，避免"只懂概念不会用"或"只会点工具不懂为啥"。

### 初级（L0+L1）：走进 AI、读懂 AI

- **技术线**：AI 是什么（ML/DL/大模型/智能体名词）、常见工具速览（DeepSeek/豆包/通义/ Copilot）、提示词基础（CO-STAR）、安全与保密底线
- **行业线**：你已经在用的 AI（语音输入/地图/垃圾过滤）、AI 在制造业的 5 个最常见场景预览、国家为什么要搞"人工智能+"
- **融合改造点**：以 Andrew Ng 非技术四模块为骨架，把"机器学习项目流程"翻译成"你们车间一次质量改善的流程"，零公式零代码

### 中级（L2+L3）：看懂制造业 AI、上手干

- **技术线**：制造业核心场景原理（视觉质检/预测维护/排程/能耗）、数据从哪来（不编程）、知识库+RAG 搭助手、提示词进阶
- **行业线**：政策逐条解读（国家要什么、补贴/标杆怎么拿）、陕汽双案例拆解（设备AI预维护10秒预测、AI视觉检测30秒 vs 人工2-3小时）、分岗位实战工作坊
- **融合改造点**：**直接拿 tertiarycourses 的 10 个活动包当母体**—— waste walk/AI机会扫描、SIPOC、预测维护决策、AI视觉质检、接地GenAI标准作业、Lean-AI试点章程（含ROI/PDCA），把英文 mock data 换成**中国制造业语境**，补上陕汽数据

### 高级（L4）：AI 战略规划与治理（弱化"AI工厂"强指向）

- **技术线**：智能工厂梯度（基础级→卓越级→领航级）、云-边-端架构、工业大模型/小模型、数字孪生、ROI 指标测算（OEE/MTBF/MTTR/不良率）
- **行业线**：组织与人才（数字工匠、全员素养、内训师）、AI 伦理与分类分级、八支柱赋能操作系统
- **融合改造点**：KAIST 技术深度 + 哈佛CS50概念 + MIT Foundation Models（非技术管理层视角）+ GitHub 企业 AI 赋能八支柱（倡导者/实践社区/分级工具政策/DRI/指标）

## 五、教学手法（小白友好八条）

1. **先去神秘化**：第一节课就讲"你手机里全是 AI"，消除距离感
2. **微课化**：单节 5–10 分钟，情景短片式，不拖堂
3. **零代码**：全程用现成工具，不装环境不写脚本
4. **情景化**：每个概念配一个车间/办公室真实小故事
5. **多轮对话式**：提示词用"角色+任务+约束"模板，当场试
6. **岗位分组实战**：生产/质量/设备/采购/办公各自做自己的任务
7. **证据清单**：每个活动交一份"看得见的产出"（对标 tertiarycourses 的 evidence checklist）
8. **考核轻量化**：不考试，交作品+同伴互评+讲师点评
