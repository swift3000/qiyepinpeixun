## 1. 总体设计

### 1.1 三级进阶模型
- **初级 · 入门层**：会用 AI 工具，消除恐惧（对象：全员 / 一线，技术小白）
- **中级 · 落地层**：用 AI 解决真实场景（对象：业务骨干 / 班组长 / 工程师）
- **高级 · 规划层**：能规划 AI 工厂、管 ROI、推组织变革（对象：管理层 / 数字化负责人）

### 1.2 设计原则
- **小白优先**：先去神秘化，再教工具；微课件（5–15 分钟）、情景化、不碰代码。
- **角色分轨**：按岗位（生产 / 质量 / 设备 / 采购 / 办公）设计内容，避免"一套讲义讲全公司"。
- **实操为王**：每个模块配真实任务 / 工作坊，"学完就能用"。
- **政策背书**：每级嵌入国家 / 行业政策。
- **可度量**：每级有考核与认证；企业侧有采纳率 / 业务指标看板（对标 GitHub 指标）。

## 2. 初级 · 入门层（会用 AI）

- **目标人群**：全员、一线员工、零基础非技术岗
- **建议时长**：12–16 课时（8 节微课 × 1.5h，或线上自学 + 1 天面授）
- **教学目标**：建立 AI 直觉、消除恐惧、掌握 3–5 个通用工具、守住安全底线

| 模块 | 课时 | 内容要点 |
|---|---|---|
| M1 AI 是什么 | 1.5h | 名词定义（AI / ML / DL / 大模型 / 智能体）、发展史、AI 与传统自动化的区别、Industry 4.0/5.0 |
| M2 AI 能 / 不能做什么 | 1.5h | 幻觉、能力边界、何时必须人拍板；"你已经在用 AI 了"（语音 / 地图 / 垃圾过滤） |
| M3 工具速览 | 2h | DeepSeek、豆包、文心一言、通义、Copilot；制造业轻量工具（设备点检 APP、AI 看板、智能客服） |
| M4 提示词基础 | 2h | CO-STAR 框架、"角色 + 任务 + 约束"、多轮对话、迭代优化 |
| M5 岗位微场景 | 3h | 按角色分组练真实任务（写邮件 / 会议纪要 / 查标准 / 排班表） |
| M6 安全与保密底线 | 1.5h | 什么数据不能喂、企业信息合规、分级使用政策（对标 GitHub 两级工具政策） |

- **考核**：线上小测（15%）+ 实操练习（提交 3 个真实任务 AI 产出，35%）+ 学习打卡（50%）
- **产出**：学员能独立用 AI 完成 3 个本职场景任务

## 3. 中级 · 落地层（用 AI 解决场景）

- **目标人群**：业务骨干、班组长、工程师（生产 / 质量 / 设备 / 供应链）
- **建议时长**：24 课时（8 模块 × 3h，参考 Industrial-AI 结构但"低代码化"）
- **教学目标**：识别高价值 AI 场景、用工具 / 平台落地、独立设计改善方案

| 模块 | 课时 | 内容要点 | 标杆 / 案例 |
|---|---|---|---|
| M1 制造业 AI 与机会地图 | 3h | AI 在制造的价值与 ROI、机会识别画布（生产 / 设备 / 质量 / 供应链） | 国家"AI+制造"专项行动 |
| M2 预测性维护与设备分析 | 3h | IoT 传感、时序数据、故障预测、条件维护 | 陕汽设备 AI 预维护（10 秒预警） |
| M3 机器视觉智能质检 | 3h | 缺陷检测、表面 / 尺寸检测、异常检测 | 陕汽 AI 视觉检测（30 秒 vs 人工 2–3h） |
| M4 生产优化与供应链 | 3h | 瓶颈分析、需求预测、库存优化、排产调度、KPI 监控 | — |
| M5 生成式 AI 与知识库助手 | 3h | LLM、RAG、搭企业私有知识库、SOP 生成、维修日志摘要 | 迷你项目：制造助手 |
| M6 AI 项目落地与变革管理 | 3h | AI 生命周期、数据就绪度、系统与 API 集成、人员技能提升、变更管理、采纳路线图 | — |
| M7 负责任 AI 与未来工厂 | 3h | 伦理、可解释、人监督、网络安全、治理、自主工厂 | 政策安全章节 |
| M8 场景实战工作坊 | 3h | 分组做迷你项目并汇报（预测维护看板 / AI 质检 / 智能供应链 / 制造助手 四选一） | — |

- **教学法（沿用参考体系配比，适配面授）**：互动讲授 30% / 演示 20% / 带练 25% / 案例讨论 10% / 小组练习 10% / 迷你项目 5%
- **考核（沿用参考体系权重）**：小测 15% + 实操 35% + 案例 20% + 迷你项目 30%
- **工具（低代码 / 平台化，避开 Python 建模）**：DeepSeek / 通义 + 知识库平台（自建 RAG）+ MES/BI 看板 + 设备点检 APP；演示级可用 Colab / Streamlit

## 4. 高级 · 规划层（规划 AI 工厂 + 组织变革 + ROI）

- **目标人群**：CIO / CDO / 数字化负责人、厂长、战略 / 运营高管
- **建议时长**：16–24 课时 + 2 天工作坊 + 标杆参访（对标陕汽"数字工匠 / 青蓝蓄能站"）
- **教学目标**：能规划智能工厂、选型技术架构、算清 ROI、主导组织级 AI 赋能落地

| 模块 | 课时 | 内容要点 |
|---|---|---|
| H1 智能工厂梯度与战略 | 3h | 基础级 → 卓越级 → 领航级（对标陕汽晋级路径）；国家"AI+制造"目标（2027：1000 工业智能体 / 500 场景 / 1000 标杆） |
| H2 技术架构选型 | 3h | 云-边-端、工业大模型 / 小模型、数字孪生、工业智能体、5G+AI |
| H3 数据治理与首席数据官 | 2h | 数据管理能力成熟度、CDO 制度、"模数共振" |
| H4 AI 项目 ROI 与指标 | 3h | OEE / MTBF / MTTR / 不良率 / 能耗；对标 GitHub 采纳指标（MAU/MEU、用户分层、业务影响） |
| H5 组织级赋能操作系统 | 4h | **核心**，改编自 GitHub 八支柱：AI 倡导者、实践社区、学习发展、培训培训师、分级工具政策、DRI 专职、高管背书、数据驱动指标 |
| H6 安全、伦理与治理 | 2h | 分类分级、幻觉防控、AI 伦理、合规 |
| H7 沙盘推演与标杆参访 | 工作坊 2 天 | 拆解陕汽 / 灯塔工厂，做本企业 AI 规划与路线图沙盘 |

- **考核**：规划方案（沙盘产出）+ 路线图答辩

## 7. 企业级交付与推广模型（改编自 GitHub 八支柱）

**八大支柱**：高管背书 / 分级工具政策 / L&D 学习发展 / 数据驱动指标 / 专职 DRI / AI 倡导者 / 实践社区 / 负责任使用

**三阶段落地**：
- **0–30 天 奠基**：赞助 + DRI + 分级政策 + 指标基线 + 全员发布
- **30–90 天 起势**：倡导者计划 + 实践社区 + 资源中心 + 标杆秀
- **持续规模化**：培训培训师 + ROI 看板 + 定期问卷

**指标看板**：采纳率 MAU/MEU、用户分层（铁粉 / 偶尔 / 尝鲜）、业务影响（OEE、停机、不良、能耗）
